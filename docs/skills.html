The output产物

What a distilled skill looks like.蒸出来的 skill 长什么样。

A whetstone skill is a portable, runtime-neutral package: a SKILL.md the runtime selects on, platform values fenced into params/<platform>.md, and pitfalls split out. Every example on this page is a generic placeholder — real skills carry your own platform values and stay in a private repo. whetstone 的 skill 是一个可移植、跟 runtime 无关的包：一份 runtime 据以挑选的 SKILL.md，隔离到 params/<platform>.md 的平台值，以及单独拆出来的坑库。本页所有例子都是通用占位 —— 真实 skill 带着你自己的平台值，放在私有仓里。

Usage用法

How to use one.怎么用一个 skill。

  1. 1

    Trigger it触发

    Say what you're doing in words its description covers; the runtime matches the description and loads the body.用它 description 里覆盖到的说法描述你在做的事，runtime 按 description 匹配后加载正文。

  2. 2

    Swap platform换平台

    New chip or SDK version → add one params/<platform>.md. The L1/L2 body stays put.换芯片或 SDK 版本 → 加一份 params/<platform>.md,L1/L2 正文不动。

  3. 3

    Keep it honest and findable保持可信、好找

    After adding or editing a skill: whetstone verify (evidence), whetstone lint (menu overlaps) and whetstone index (grouped catalog).新增或修改 skill 后跑：whetstone verify（证据）、whetstone lint（菜单重叠）、whetstone index（分组目录）。

    Move machines换机器
